# 江城故人 李白篇 Demo

一个使用现有水墨美术素材制作的单页互动叙事游戏。李白路线已完整实现；屈原、伯牙与钟子期、张之洞保留为后续可扩展入口。

## 已实现流程

1. 江城开场与四人选卡
2. 李白御笔飞行转场
3. 江城地图抵达黄鹤楼
4. 玉笛、黄鹤、诗壁三处寻幽
5. 选择意象并生成、修改四句共题诗
6. 生成本地内容摘要与可下载记忆卡 PNG

当前链上状态明确标记为“演示回执 · 未登记 BOT Chain”，没有模拟真实交易成功。

## 本地运行

在本目录执行：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `dist/index.html`：游戏画面与交互结构
- `dist/styles.css`：水墨国风界面、动效和响应式布局
- `dist/game.js`：剧情状态、寻幽进度、题诗与记忆卡下载
- `dist/assets/`：部署用美术资源副本

后续接入真实 AI、会话记忆或 BOT Chain 时，可以保留现有前端状态机，替换题诗生成和封存逻辑。
